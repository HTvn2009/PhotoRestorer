GUIDE

Help

PicRes restores and colorizes old or damaged photos, then creates a clear description of what appears in the image. Add an image name, upload a JPG, PNG, or WEBP file, write any context you know, then run restoration. After the result is ready, save it to My Gallery or share a saved project with a link.

Use real photographs that show people, family memories, buildings, landmarks, cultural objects, documents, artifacts, ceremonies, or historical scenes. The image should clearly show the main subject and should not be larger than 3 MB. Avoid screenshots, cartoons, AI images, heavily edited pictures, or images where the important subject is too small or hidden.

Write only information you already know, such as the person, place, date, event, object name, or family story connected to the photo. If you are unsure, leave the context field blank or use cautious wording. The description should preserve useful history without inventing facts.
